# Endless-Driving-Game-
This will be a Unity 3D game where you will drive endlessly on a city road with multiple obstacles and levels, there will be a score on how far you will get -- Like the  T-Rex Runner on google when you have no connection. You'll also be able to pick your car and maybe I'll implement multiple maps.


Week 1: Completed Car movement and input and refined physics. Also completed the follow Camera using Cinemachine. Started to work on the map and obstacles as well as the endless map script. 

Week 2: I worked on my collision script and completed the map. Tried to debug the endless map script, which was cloning too fast. I implemented custom oil and bomb obstacles which provide tire slip and slowdown. 

Week 3: Finished the collider scripts and debugged inoperative obstacles. Added a small speed boost powerup. Endless map script still is not working, will be used as a static showcase for presentation since I wasn't able to finish in time. Game runs smoothly. Finished working on the presentation.
